BERBER RANDEVU TAKIP
====================

KURULUM (bir kez)
1) Bilgisayarda Python 3.10+ kurulu olmali (python.org; kurarken "Add to PATH" kutusunu isaretleyin).
2) Bu klasorde komut satirini acip:   pip install -r requirements.txt

KULLANIM
- baslat.bat          : programi acar, tarayicida otomatik acilir (sadece bu bilgisayar).
- baslat_telefon.bat  : ayni Wi-Fi'deki telefonlardan da acilir.
                        Telefonda  http://BILGISAYAR-IP:5050  yazin.
                        Windows guvenlik duvari sorarsa "Ozel ag"a izin verin.

NOT: Telefon baglanabilsin diye bilgisayar acik ve program calisiyor olmali.
Veriler berber.db dosyasinda tutulur.

YEDEK: berber.db dosyasini kopyalamak yeterlidir. Yeni bilgisayarda ayni dosyayi koyunca her sey gelir.

YETKILI GIRISI (PIN)
- Ayarlar (disli simgesi) ve Hakedis (saat simgesi / sol menu) sadece PIN ile acilir.
  Ilk acilista PIN belirlersiniz (4-12 rakam). 30 dk islem yapilmazsa oturum kapanir.
- Ayarlar: berber ekle/cikar/ad degistir + berber basina hakedis orani (%), hizmet ve fiyatlar,
  dukkan adi ve calisma saatleri, PIN degistirme.
- Hakedis: secilen tarih araliginda sadece "Geldi" isaretli islerden berber basina ciro,
  hakedis (ciro x oran) ve dukkan payi. Satira tiklayinca islemler acilir. CSV olarak indirilir.
- PIN unutulursa: programi kapatin, program klasorune bos bir PIN_SIFIRLA.txt dosyasi koyup
  yeniden acin; PIN silinir, yenisini belirlersiniz. Randevu verileri etkilenmez.

TAKVIM
- Sol menuden bir berbere tiklayinca sadece onun takvimi gorunur (tekrar tiklayinca hepsi).
- Her randevu kutusunda saat, musteri, hizmet ve tutar (TL) gorunur; renk berbere gore, yesil = geldi.
- Bos bir saate tiklayin: yeni randevu. Dolu kutuya tiklayin: duzenle / geldi / gelmedi / iptal.
- Ayni berberde cakisan randevuya izin verilmez; farkli berberlerde ayni saat serbesttir.
- Hizmet secince sure ve ucret otomatik dolar, elle de degistirebilirsiniz.
- Ozet sekmesi: berber bazinda gelen/gelmeyen sayisi, kazanc ve beklenen ciro.
- Musteri adi yazarken eski musteriler onerilir, telefon otomatik gelir.

EXE URETMEK (Python kurmadan calisan tek dosya)
1) GitHub'da yeni bir depo ac (private olabilir), bu klasorun TUM icerigini yukle
   (.github klasoru dahil; gizli klasor oldugu icin yuklemeyi unutma).
2) GitHub bunu otomatik derler: Actions sekmesi -> "Release" isi yesil olunca
   sag taraftaki Releases bolumunden BerberRandevu.exe indirilir.
3) exe'yi dukkan bilgisayarina koyup cift tikla. Program kendi penceresinde acilir
   (siyah konsol yok); pencereyi kapatinca program tamamen kapanir.
   berber.db exe'nin yanina olusur. Pencere icin Edge veya Chrome kurulu olmalidir
   (Windows 10/11'de Edge zaten vardir).
   Telefon icin: exe kisayolunun Ozellikler > Hedef satirinin sonuna  --ag  ekleyin.
   Telefon adresi Ayarlar sekmesinde yazar. Telefon calissin diye pencere acik kalmali.
4) ONLINE GUNCELLEME: program acilirken GitHub'daki son surume bakar. Yeni surum varsa ustte
   sari bir serit cikar, "Simdi guncelle"ye basinca yeni exe iner, program kendini yenileyip
   yeniden acilir (berber.db'ye dokunmaz). Ayarlar > "Guncellemeyi kontrol et" ile elle de bakilir.
   Bunun calismasi icin GitHub deposu PUBLIC (acik) olmalidir; depoda sifre/anahtar yoktur.
   Depo adi app.py icindeki GUNCELLEME_REPO satirindadir (veloxtr/berber-randevu).
5) Yeni surum: version.py icindeki VERSION'u artirip main'e gonder, GitHub yeniden derler.
   (Elle derlemek icin Windows'ta:  pip install pyinstaller  ve  python build.py)

ILERIDE
- Sunucu (app.py) ve arayuz (static/index.html) ayridir; internete tasimak veya
  WhatsApp hatirlatma eklemek icin yapi hazirdir.
- Guvenlik: --ag modu sifre istemez, sadece guvendiginiz ag icin kullanin.
